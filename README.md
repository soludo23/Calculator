SimpleCalc - Basic Calculator Web App

A lightweight, fast, and responsive calculator for everyday math. Clean UI with keyboard support and dark mode. No ads, no login, works offline.

!SimpleCalculator Screenshot(screenshot.png)

 Features

- **Core Operations**: Addition `+`, Subtraction `-`, Multiplication `×`, Division `÷`
- **Extra**: Decimal `.`, Percentage `%`, Clear `C`, Backspace `⌫`
- **UX**: 
    - Full Keyboard Support: `0-9, +, -, *, /, Enter, Backspace, Esc`
    - Responsive: Works on Mobile, Tablet, Desktop
    - Dark / Light Mode Toggle
    - Instant Results
- **Tech**: Zero dependencies. Pure HTML, CSS, JavaScript
- **Storage**: Remembers your last theme with LocalStorage

Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript ES6
- **Layout**: CSS Grid + Flexbox
